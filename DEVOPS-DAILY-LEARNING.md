# DevOps Daily Learning Notes

A quick reference for consistent DevOps practice.

## Core Areas

- Linux: files, permissions, processes, services, and shell commands
- Git: branches, commits, merges, and pull requests
- Docker: images, containers, volumes, and networks
- Kubernetes: Pods, Deployments, Services, ConfigMaps, and Secrets
- CI/CD: automated build, test, and deployment workflows
- Terraform: infrastructure as code and reusable modules
- Monitoring: metrics, dashboards, and alerting

## Daily Practice

1. Learn one concept.
2. Practise it with a small hands-on task.
3. Record the commands and important observations.
4. Review errors and document the fix.

## Goal

Build reliable, secure, and repeatable infrastructure through continuous practice.
